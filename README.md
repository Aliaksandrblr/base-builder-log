# Base Builder Log

This repository documents my learning journey as a Base ecosystem builder.

## Purpose
The goal of this repository is to:
- Build a consistent public contribution history
- Learn Base from a practical builder perspective
- Document notes, experiments, and daily progress
- Create a clean, readable builder-style repository

## Repository structure
- daily-logs/ — short daily progress logs
- resources/ — useful links, checklists, and references
- base-notes/ — concise technical notes about Base and L2 concepts
- mini-experiments/ — small drafts and experiments (added gradually)

## Status
Active and continuously updated.
